# Julio Maculan — PCB design portfolio

[View the portfolio](https://juliomacmac.github.io/)

Seven complete Altium PCB viewers show copper, silkscreen and components. The PDM also includes all seven schematic sheets. Other boards contain PCB documents only; their schematics are excluded.

Viewer ZIP archives are public and downloadable, including editable PCB documents and, for the PDM only, schematic documents. Hiding the download button does not restrict access to these archives.

Run `node build.mjs` after editing project-data.json. GitHub Pages serves the main branch from the repository root.
